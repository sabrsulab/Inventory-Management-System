# Environment Information:
* Please ensure that you install pandas and xmlswriter for your python environment so that the program will work properly without throwing errors.
* These programs were made and tested using python version 3.13 and the latest version of pandas and xlswriter and the program was tested using a Windows environment.

# How to Use the Program:
* This is a locally-stored inventory management tool that allows the user to implement a barcode scanner to manage inventory using one computer, rather than having a pre-requisite for setting up a server or account to do so. 
* I did not implement a login for this software because it would have defeated the purpose of creating the software for me.
* If you would like to make the software boot with windows startup, create a shortcut to checkout.py and main.py in the start folder of Windows, making sure to keep them in the same folder as the database.
* If you would like to make a fresh database and don't care about the stored data, you can delete the existing database and the program will generate a new one once you restart it.
